# Node Batch — Course Code


## Topics covered

→ Intro to Node.js (history, advantages) <br>
→ Node.js installation & VS Code setup <br>
→ REPL and Global objects <br>
→ Node.js modules (core, local, third-party) <br>
→ Create custom server using `http` and `fs` modules <br>
→ What is NPM <br>
→ Install and use Express (EJS templating) <br>
→ CRUD using static arrays and then with MongoDB (Mongoose schemas) <br>
→ File management using Multer (upload, view, delete) <br>
→ Middleware, static files, and MVC structure <br>
→ Routing and controllers in Express <br>
→ Async / Await, try/catch patterns <br>
→ Building real projects:  Admin Panel etc. <br>
→ Manual authentication using cookies (signup/signin/secure pages) <br>
→ Authentication using Passport.js (local strategy + sessions) <br>
→ JWT-based Register & Login APIs <br>
→ REST API design, Postman collection and testing (GET/POST/PUT/PATCH/DELETE) <br>
→ Nodemailer (OTP for forgot password) <br>
→ Role based/hierarchical access (admin, manager, employee) <br>
→ Advanced API structure <br>
